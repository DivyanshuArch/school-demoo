# School Demo Websites & Minimalist Design Variants

A collection of high-end educational institution demo websites, featuring **4 distinct minimalist design variants** alongside the original flagship prep academy. Built with zero dependencies (HTML5, Tailwind CSS via CDN, Google Fonts, and Lucide Icons).

---

## 🎨 Minimalist Design Variants Overview

### 1. [Variant 1: Swiss / Nordic Minimal](variant-swiss-minimal.html) (`variant-swiss-minimal.html`)
- **Institution**: *Nordic International Academy* (Copenhagen / Stockholm style)
- **Design Philosophy**: Radical clarity, geometric typography (`Space Grotesk`), razor-sharp grid borders, asymmetric imagery, and electric cobalt blue accents (`#2563eb`).
- **Focus**: High intellectual autonomy, architectural daylight, and structured scientific inquiry.

### 2. [Variant 2: Warm Editorial Ivy](variant-editorial-ivy.html) (`variant-editorial-ivy.html`)
- **Institution**: *Eldridge Collegiate Academy* (New England literary prep)
- **Design Philosophy**: Magazine-style literary minimalism, British racing green (`#163826`), warm alabaster stone (`#FAF7F2`), and refined serif typography (`Playfair Display`).
- **Focus**: Harkness discussion tables, classical humanities, pastoral house traditions, and quiet intellectual depth.

### 3. [Variant 3: Future STEAM & Innovation](variant-future-steam.html) (`variant-future-steam.html`)
- **Institution**: *Nexus Horizon STEAM Academy* (Next-Gen Tech & Science)
- **Design Philosophy**: Sleek dark obsidian palette (`#090D16`), luminous indigo and cyan micro-accents (`#6366F1`, `#06B6D4`), and modular dashboard cards (`Outfit`).
- **Focus**: Artificial intelligence, synthetic biology, astrophysics dome, and student patents.

### 4. [Variant 4: Organic Zen & Nature](variant-zen-nature.html) (`variant-zen-nature.html`)
- **Institution**: *Sylvan Crest Forest & Arts Academy* (Ecological / Progressive Arts)
- **Design Philosophy**: Soft forest sage (`#264234`), eucalyptus leaf (`#EBF2ED`), warm sand parchment (`#FDFBF7`), and organic curves (`Fraunces`).
- **Focus**: Nature as primary educator, woodworking & ceramic ateliers, emotional wellness, and outdoor living.

## 🚀 How to Run & Preview

Open any variant file directly in your browser:
```bash
# Preview via Python HTTP server
cd "website demos/school-demo"
python3 -m http.server 8000
```
Then visit:
- **Variants Hub**: `http://localhost:8000/variants-hub.html`
- **Variant 1 (Swiss Minimal)**: `http://localhost:8000/variant-swiss-minimal.html`
- **Variant 2 (Editorial Ivy)**: `http://localhost:8000/variant-editorial-ivy.html`
- **Variant 3 (Future STEAM)**: `http://localhost:8000/variant-future-steam.html`
- **Variant 4 (Zen Organic)**: `http://localhost:8000/variant-zen-nature.html`
- **Original Flagship**: `http://localhost:8000/index.html`

*Note: All pages include a floating variant switcher bar at the bottom to easily hop between designs in one click.*
